1. Présentation de GESTPAL

GESTPAL est une application web de gestion des pesées palette conçue pour les sites d'export de cacao et de produits agricoles. Elle permet de :

  • Créer et suivre des pesées (une pesée = un lot, plusieurs palettes)
  • Capturer les poids en temps réel depuis un indicateur de pesage RS232
  • Gérer automatiquement les règles métier de l'export cacao (10 palettes, 385 sacs)
  • Générer des rapports et tickets imprimables
  • Gérer les référentiels (clients, fournisseurs, transporteurs, etc.)
ℹ Architecture GESTPAL est une application serveur démarrée sur l'ordinateur de pesée. Tous les postes du réseau local peuvent y accéder via un navigateur web (Chrome ou Edge recommandés) à l'adresse http://[IP-du-serveur]:3000.

2. Connexion et navigation

Se connecter

  1. Ouvrez Chrome ou Edge et saisissez l'adresse du serveur GESTPAL.
  2. Entrez votre identifiant et votre mot de passe.
  3. Cliquez Connexion. La session reste active 12 heures.
💡 Compte par défaut À l'installation, le compte administrateur est admin / admin123. Changez ce mot de passe dès la première utilisation via Utilisateurs → Modifier.

3. Créer une nouvelle pesée

Une pesée représente un bon de livraison ou un lot de production. Elle regroupe plusieurs palettes pesées successivement.

  1. Cliquez Nouvelle pesée dans la barre de navigation.
  2. Remplissez les informations du lot (voir tableau ci-dessous).
  3. Posez les palettes vides sur la bascule, attendez la stabilisation, puis cliquez 📥 Capturer la tare.
  4. Cliquez ▶ Démarrer la pesée.

ℹ Saisie à la volée Les champs Client, Fournisseur et Transporteur acceptent une saisie libre. Si la valeur ne correspond à aucun référentiel connu, GESTPAL crée automatiquement une nouvelle entrée. Vous pouvez l'affiner plus tard via le menu Référentiels.

Preset Export Cacao

Si la pesée concerne un lot cacao standard à l'export, cliquez 📦 Preset Export Cacao pour préremplir automatiquement : 10 palettes, 385 sacs (9 × 40 + 1 × 25).

4. Pesée en cours — Enregistrer les palettes

Une fois la pesée démarrée, vous accédez à l'écran de pesée en temps réel.

Interface principale

L'écran est divisé en deux zones :

  • Gauche : Afficheur de poids (vert = stable, jaune = en mouvement) + formulaire de capture
  • Droite : Totaux en cours (palettes, sacs, poids brut, poids net) + liste des palettes enregistrées

Enregistrer une palette

  1. Posez la palette chargée sur la bascule.
  2. Attendez que la valeur passe en vert STABLE.
  3. Cliquez 📥 Capturer le poids brut — le poids s'inscrit dans le champ (lecture seule).
  4. Saisissez le nombre de sacs sur la palette.
  5. Cliquez ✅ Enregistrer la palette.
⚠ Champs poids en lecture seule Les champs Tare palettes et Poids brut ne peuvent être remplis que par les boutons de capture bascule. Cela garantit l'intégrité des mesures.

Tuteurs de progression

Quand des quotas sont définis, les tuiles affichent le format X / Y (ex: 3 / 10 palettes). Une barre d'information sous le formulaire indique les palettes et sacs restants. La tuile passe en orange quand le quota est atteint.

Actions en cours de pesée

ActionDescription
⏸ InterrompreSuspend la pesée (camion absent, pause). On peut la reprendre.
▶ ReprendreReprend une pesée interrompue.
🖨 TicketImprime le ticket de pesée courant (format ticket thermique).
🔒 ClôturerFinalise la pesée. Plus aucune modification possible. Au moins une palette requise.
🚫 AnnulerAnnule définitivement la pesée.

Supprimer une palette enregistrée

Cliquez le bouton 🗑 sur la ligne de la palette dans le tableau. La suppression n'est possible que si la pesée est EN COURS ou INTERROMPUE.

5. Règle Export Cacao (preset 10 palettes)

Le preset Export Cacao applique la règle métier standard : 9 palettes de 40 sacs + 1 palette de 25 sacs = 385 sacs.

ℹ Détection automatique Le mode Cacao s'active quand la pesée a exactement 10 palettes et 385 sacs maximum. Le champ "Nombre de sacs" est remplacé par une tuile "SACS PROPOSÉS" qui affiche le nombre attendu pour chaque palette.

Workflow palette par palette

  1. Capturez le poids brut de la palette.
  2. Cliquez ✅ Enregistrer la palette. Une boîte de dialogue s'ouvre.
  3. Palettes 1 à 9 : la boîte propose 40 sacs. Si c'est correct, cliquez ✅ Confirmer 40 sacs.
  4. Palette 10 : la boîte propose 25 sacs (dernière palette). Confirmez.
  5. Si le nombre de sacs est différent, cliquez ✏ Saisir le nombre réel, entrez la vraie quantité. Cette palette sera marquée QL (queue de lot) — fond jaune dans le tableau.
💡 Queue de lot Une palette marquée QL indique un écart par rapport au standard. Elle est visible dans le tableau et dans les rapports pour faciliter le contrôle qualité.

7. Rapports et impressions

Rapport global

  1. Cliquez Rapports dans la barre de navigation.
  2. Définissez les filtres : période, produit, client, site, statut.
  3. Le tableau se met à jour automatiquement avec les totaux.

Actions

BoutonDescription
📊 Export CSVTélécharge les données filtrées au format tableur (Excel, LibreOffice)
🖨 ImprimerOuvre un rapport HTML prêt à imprimer / enregistrer en PDF (Ctrl+P)

Ticket palette individuel

Depuis la pesée en cours ou terminée, cliquez 🖨 Ticket pour obtenir un ticket de style thermique avec tous les détails : lot, client, fournisseur, palettes, poids net, tare, etc.

Ajouter / Modifier un référentiel

  1. Cliquez sur l'onglet du référentiel souhaité.
  2. Cliquez ➕ Ajouter ou le bouton ✏ sur une ligne existante.
  3. Remplissez le Code (court, unique) et le Libellé.
  4. Cliquez Enregistrer.
💡 Création à la volée Lors d'une nouvelle pesée, si vous tapez un nom de client/fournisseur/transporteur inconnu dans le champ, GESTPAL le crée automatiquement. Vous pourrez le compléter (code, adresse, etc.) dans les Référentiels plus tard.

9. Configuration de la bascule RS232

La configuration RS232 est accessible uniquement aux administrateurs via le menu 🔧 Bascule.

⚠ Redémarrage automatique Après chaque enregistrement de la configuration, le pont bascule redémarre automatiquement (délai ~7 secondes). Le badge de poids se réinitialise le temps du redémarrage.

Paramètres série

ParamètreDescriptionValeur typique
Port COMPort série Windows de l'indicateurCOM3, COM4, COM6…
Vitesse (baud)Vitesse de transmission9600
Bits de donnéesLongueur mot8
ParitéBit de paritéAucune
Bits de stopBits de stop1

Paramètres de trame

ParamètreDescriptionExemple
Délimiteur de finCaractère(s) de fin de trame\r\n ou \r
Regex poidsExpression régulière pour extraire le poids (groupe 1 = valeur)([+-]?\d+(?:[.,]\d+)?)
Marqueur stableTexte indiquant que la mesure est stableST ou ww

Tester la configuration

La section Testeur de trame permet de simuler une trame reçue et de vérifier que la regex extrait correctement le poids — sans connexion physique à l'indicateur.

Détecter les ports disponibles

Cliquez 🔍 Détecter les ports pour lister automatiquement les ports COM disponibles sur le serveur.

10. Administration — Paramètres avancés

Le menu ⚙ Paramètres est réservé aux administrateurs et permet de réinitialiser la base de données.

⚠ Action irréversible La réinitialisation supprime définitivement des données. Cette opération ne peut pas être annulée.

Modes de réinitialisation

ModeCe qui est suppriméCe qui est conservé
Pesées uniquement Toutes les pesées et lignes palette Référentiels, utilisateurs, configuration
Réinitialisation complète Pesées + tous les référentiels + utilisateurs (sauf admin) Compte admin (mot de passe remis à admin123)

Procédure de réinitialisation

  1. Cliquez le bouton de réinitialisation souhaité.
  2. Une boîte de dialogue de confirmation s'ouvre.
  3. Tapez exactement REINITIALISER dans le champ de confirmation.
  4. Cliquez Confirmer la réinitialisation.

Gestion des utilisateurs

Via le menu Utilisateurs, l'administrateur peut :

  • Créer des comptes peseurs
  • Modifier les mots de passe
  • Activer / désactiver des comptes
  • Changer les rôles (ADMIN / PESEUR)

11. Installer GESTPAL sur le bureau (PWA)

GESTPAL peut être installé comme une application de bureau depuis Chrome ou Edge, sans passer par un installateur.

Installation sur Chrome / Edge

  1. Ouvrez GESTPAL dans Chrome ou Microsoft Edge.
  2. Cliquez l'icône ⊕ ou 💻 Installer dans la barre d'adresse (à droite).
  3. Cliquez Installer dans la boîte de dialogue.
  4. GESTPAL apparaît maintenant dans le menu Démarrer et sur le bureau.
💡 Avantages de l'installation PWA L'application s'ouvre dans sa propre fenêtre (sans barre d'adresse navigateur), elle est accessible depuis le bureau comme n'importe quel logiciel, et un raccourci est créé automatiquement.
ℹ Mode hors-ligne GESTPAL nécessite la connexion au serveur pour fonctionner. L'installation PWA améliore l'ergonomie mais ne permet pas un fonctionnement hors-ligne.

12. Dépannage courant

SymptômeCause probableSolution
Badge poids bloqué à 0 Le pont bascule n'est pas démarré ou n'est pas connecté Vérifiez que PM2 affiche gestpal-bridge: online. Vérifiez le câble RS232 et le port COM dans la configuration bascule.
Badge poids jaune permanent L'indicateur envoie des mesures instables Normal si la charge est en mouvement. Vérifiez le paramètre "Marqueur stable" dans la configuration bascule.
Poids ne s'actualise pas après sauvegarde config Le pont bascule redémarre (délai normal ~7 s) Attendez 10 secondes. Si le problème persiste, vérifiez les logs : pm2 logs gestpal-bridge
Session expirée — redirection vers login Session de 12 h expirée Reconnectez-vous. Veillez à ne pas fermer l'application pendant une pesée longue.
Erreur "Quota palettes atteint" Le nombre max de palettes défini est atteint Clôturez la pesée actuelle et créez-en une nouvelle, ou augmentez le quota dans les paramètres de la pesée.
Erreur "Dépassement quota sacs" Le nombre de sacs saisi dépasse le quota restant Ajustez le nombre de sacs saisi ou clôturez et créez une nouvelle pesée.
Client/Fournisseur introuvable dans le menu déroulant L'entrée n'existe pas dans les référentiels Tapez directement le nom dans le champ : il sera créé automatiquement à la validation.
La page affiche "Activation GESTPAL" Licence manquante ou expirée Contactez votre revendeur avec le Code Machine affiché pour obtenir une nouvelle clé de licence.
L'application ne s'ouvre plus Le serveur GESTPAL n'est pas démarré Sur le serveur, exécutez pm2 restart all ou relancez demarrer-gestpal.bat.
Rapport CSV illisible dans Excel Problème d'encodage ou de séparateur Ouvrez Excel → Données → Importer depuis texte/CSV → choisissez UTF-8 et virgule comme séparateur.

Contacts et support

En cas de problème non résolu, contactez votre revendeur GESTPAL avec :

  • Le Code Machine (visible dans l'écran d'activation ou dans Paramètres)
  • La capture d'écran de l'erreur
  • Les logs du serveur : pm2 logs gestpal-server --lines 50
